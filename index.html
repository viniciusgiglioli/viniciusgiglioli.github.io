Flashcards Salesforce Agentforce

O que é o Prompt Builder?
Ferramenta do Salesforce que cria prompts reutilizáveis para LLMs, integrando IA aos fluxos de trabalho. Configurado no Setup (Einstein Generative AI).
O que faz o modelo Geração de Campo?
Gera conteúdo para campos específicos em registros (ex.: resumo em um campo). Configurado no Prompt Builder.
O que é o modelo Resumo de Registro?
Sumariza informações de um registro inteiro. Usado no Prompt Builder para visões gerais.
Qual a função do modelo Flex?
Integra dados de múltiplos objetos (padrão e personalizados) para prompts complexos. Configurado no Prompt Builder.
O que é o modelo E-mail de Vendas?
Cria e-mails personalizados com dados do Salesforce. Configurado no Prompt Builder.
O que são Campos de Mesclagem?
Variáveis que integram dados de registros ou serviços externos em prompts. Configuradas no Prompt Builder.
O que é Ancoragem Dinâmica?
Incorpora dados de registros automaticamente em prompts. Configurada no Prompt Builder ou Draft with Einstein.
Quais hiperparâmetros podem ser ajustados no Model Playground?
Temperatura (criatividade), Penalidade de Frequência (repetição de palavras), Penalidade de Presença (repetição de ideias). Configurados no Model Playground.
O que causa erros de limite de tokens?
Variabilidade de tokens em prompts dinâmicos por registro. Gerenciado otimizando prompts no Prompt Builder.
O que é um Fluxo de Tela no Prompt Engineering?
Fluxo com UX personalizada que coleta dados para prompts. Configurado no Flow Builder com ação 'Prompt Template'.
O que é um Fluxo disparado pelo Data Cloud?
Fluxo que integra dados unificados do Data Cloud em prompts. Configurado no Flow Builder.
Como integrar dados de um serviço REST API em prompts?
Usar campos de mesclagem de Registro de Serviço Externo. Configurado no Prompt Builder.
O que é necessário para acessar recursos de IA generativa?
Conjunto de permissões de Usuário de IA Generativa. Configurado em Permission Sets no Setup.
O que acontece se não houver lista relacionada em um prompt?
O prompt não gera resposta, pois depende dos dados. Configurado no Prompt Builder.
Qual técnica melhora a contextualização de prompts?
Usar role-play no prompt para dar contexto ao LLM. Configurado no Prompt Builder.
O que é o Einstein Copilot?
Assistente conversacional de IA que executa ações e responde perguntas no Salesforce. Configurado no Copilot Builder.
O que é a Camada de Confiança Einstein?
Camada de segurança que protege dados e audita IA. Configurada no Setup (Einstein Generative AI).
O que é Mascaramento de Dados?
Oculta dados sensíveis em prompts e respostas. Configurado na Camada de Confiança Einstein.
O que são Regras de Moderação de Conteúdo?
Filtram respostas do Copilot para seguir políticas da empresa. Configuradas na Camada de Confiança.
O que é Ancoragem Dinâmica com Recuperação Segura?
Integra dados de registros em prompts do Copilot com segurança. Configurada na Camada de Confiança.
O que são Ações do Copilot?
Tarefas como consultar ou atualizar registros, configuradas na Página de Ações do Copilot.
O que é Einstein Copilot Analytics?
Ferramenta que monitora usabilidade e ações do Copilot. Configurada no Setup (Copilot Analytics).
O que é o Model Builder?
Integra LLMs externos (ex.: AWS) ao Salesforce. Configurado no Einstein Studio Model Builder.
Como configurar permissões para ações do Copilot?
Atribuir permissões específicas em Permission Sets no Setup (ex.: Exclusão de Registro).
O que faz 'Enriquecer logs de eventos com dados de conversa'?
Mostra entradas e respostas do Copilot dos últimos 7 dias. Configurado no Setup (Einstein Copilot).
Como depurar uma ação personalizada do Copilot?
Ativar depuração dinâmica no Painel Dinâmico do Copilot Builder para ver entradas e saídas.
O que ativa a Camada de Confiança Einstein?
Ativar Einstein Generative AI no Setup.
Como o Copilot processa solicitações de usuários?
Analisa a solicitação e usa LLM para gerar respostas contextuais. Configurado no Copilot Builder.
Qual o papel do LLM em ações do Copilot?
Identifica as melhores ações e sua ordem de execução. Configurado no Copilot Builder.
Como monitorar a usabilidade do Copilot?
Usar Einstein Copilot Analytics para relatórios de ações e interações. Configurado no Setup.
Como configurar uma tarefa personalizada no Copilot?
Criar um fluxo personalizado e vinculá-lo a uma ação do Copilot no Copilot Builder.
O que garante respostas consistentes com políticas da empresa?
Regras de Moderação de Conteúdo na Camada de Confiança Einstein.
O que é o Data Cloud?
Unifica dados de várias fontes para insights acionáveis. Configurado no Salesforce Data Cloud.
O que são Data Cloud Triggered Flows?
Fluxos que usam dados unificados do Data Cloud em prompts. Configurados no Flow Builder.
O que é o Trilho de Auditoria no Data Cloud?
Armazena prompts e dados mascarados para auditoria. Configurado na Camada de Confiança com Data Cloud.
Qual API integra sistemas legados com IA generativa?
REST API, configurada no Setup (API Integrations).
O que é necessário para armazenar dados de auditoria de IA?
Provisionar o Data Cloud no Setup.
O que é o Einstein for Service?
Conjunto de recursos de IA no Service Cloud para melhorar o atendimento. Configurado no Setup (Einstein for Service).
O que é Service AI Grounding?
Ancora respostas de IA em casos, Conhecimento e notas de caso. Configurado no Einstein for Service.
O que faz o Einstein Reply Recommendations?
Sugere respostas baseadas em artigos de Conhecimento para chats. Configurado no Einstein for Service.
O que é Einstein Generative Service Replies for Email?
Gera e-mails personalizados baseados em Conhecimento. Configurado no Einstein for Service.
O que é Case Classification?
Sugere valores para campos de caso com base em interações. Configurado no Einstein for Service.
Quais objetos são usados no Service AI Grounding?
Caso, Conhecimento e Notas de Caso. Configurado no Einstein for Service.
Como reduzir o tempo de atendimento com IA?
Usar Reply Recommendations e Case Classification no Einstein for Service.
Como o Copilot ajuda agentes de serviço?
Responde perguntas com base em artigos de Conhecimento. Configurado no Copilot Builder.
O que é o Einstein for Sales?
Conjunto de recursos de IA no Sales Cloud para otimizar vendas. Configurado no Setup (Einstein for Sales).
O que é Einstein Opportunity Scoring?
Classifica oportunidades e sugere ações. Configurado no Einstein for Sales.
O que faz o Einstein Sales Insights?
Analisa chamadas para menções de concorrentes e coaching. Configurado no Einstein for Sales.
O que é Draft with Einstein?
Cria e-mails personalizados com ancoragem automática. Configurado no Email Composer (Sales Cloud).
O que é Einstein Conversation Insights?
Personaliza insights de chamadas (ex.: 50 concorrentes). Configurado no Einstein for Sales.
